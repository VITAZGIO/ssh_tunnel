# Значки интерфейса

Material Symbols (Outlined, толщина 400) от Google — лицензия Apache 2.0,
https://github.com/google/material-design-icons. Файлы взяты из пакета
`@material-symbols/svg-400@0.27.0` и лежат внутри программы: из сети ничего
не грузится.

В интерфейсе значок рисуется маской (`mask-image`) цветом текста, поэтому
цвет внутри файла не важен. Своего значка нет в наборе — дорисовать в том же
стиле: поле `0 -960 960 960`, линии 80 единиц, скругления как у соседей.
