# Ad blocking

Ads and trackers don't load in any app: a lookup of a listed name gets «no
such name» and never reaches the network. Works in **VPN mode** (phone, VPN
build on Windows and Linux).

- **Statistics**: blocked today / 7 / 30 days, a 2-week chart, the most
  blocked names and the latest ones. «allow» adds a name to the allow list.
- **Lists**: block list links (hosts or adblock format) and the allow list.
