# Device files

Browse, download and upload files of your other devices — like on
vitazgio.ru, but without a website: straight through your device network.

## Who sees what

By default **nothing** is visible to others. On each device you choose the
folders yourself: «Device files» → **«My folders»** → pick a common folder
(Photos, Downloads, Documents…) or type a path → «Share».

- A shared folder is visible to every device of your device network — view
  and download only.
- The **«can change»** checkbox (off by default) allows uploading into the
  folder, creating folders, renaming and deleting.
- The file service is reachable **only from your device network**: neither
  the internet nor your home LAN can see it. The network server knows who
  is calling — another device cannot be impersonated.
- The plugin must be added on both devices.

## Working with files

«Devices» tab → pick a device → a folder.

- Tap a photo, video or text file to view it; anything else downloads.
- **Download:** on a PC — a normal browser download; on a phone — into
  «Downloads», a retry after a break continues where it stopped.
- **«Upload here»** — files go in chunks; if the connection drops the upload
  continues by itself, and a retry continues where it stopped. A file with
  the same name is never overwritten: the new one becomes «file (2)».
- New folder, rename, delete — in folders with «can change». Deleting asks
  for confirmation, a non-empty folder asks once more.

## Phone

- For others to see phone folders, Android must give the app «All files
  access» — the «Allow» button in the «My folders» tab.
- The progress notification is shown **only while a transfer runs** and
  then goes away (Android always shows the VPN icon — that cannot be hidden).

On a PC the plugin opens in its own window right away.
