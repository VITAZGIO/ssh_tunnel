# Getting started

ssh_tunnel routes your internet through your own server over SSH. Your ISP sees
a single encrypted connection to the server — just like an admin logging into
their own machine. SSH is not blocked: half of the internet depends on it.

## What you need

- **A server** (VPS) with SSH. The cheapest one will do.
- **A key** to log into it. The app can create one for you.

## First run

1. Open **Settings → Setup wizard** and pick what you have: a new server, a
   ready server, or settings from someone who has already set it up.
2. The wizard checks the login, sets up the server and adds it to the list.
3. On the main screen press the big round button. "Protected" means it works.

## Phone

The fastest way is **Settings → Setup wizard → Connect a phone**: a QR code
appears on the screen, the phone scans it with the camera.

## Where things are

- **Main screen** — two buttons and the connection state (see "Main screen
  and modes").
- **Settings** — servers, programs, device network, appearance.
- **Plugins** — optional tools you add yourself.
- **Book** — this help. Search is at the top, source code is linked at the
  bottom.
