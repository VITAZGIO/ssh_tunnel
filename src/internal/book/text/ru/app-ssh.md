# SSH

Свой список серверов на этом устройстве и вход по ключу.

## Добавить сервер

«Добавить сервер» → имя, адрес, логин, порт (22). Адрес выбирается из
сети устройств (например, домашний сервер, даже когда ты не дома) или
«Ввести вручную» — имя или IP.

## Ключ

Ключ ed25519 программа создаёт сама при первом обращении. Закрытая часть
хранится **только зашифрованной**: на Windows — ключом учётной записи
(DPAPI), на Android — ключом Android Keystore. На Linux — файл с правами
600 в папке настроек.

**«Установить ключ»** — программа один раз спросит пароль сервера, допишет
свой ключ в `~/.ssh/authorized_keys` и проверит вход по нему. Пароль нигде
не сохраняется. Кнопка «Ключ» показывает открытую часть — её можно вставить
на сервер и руками. Установка работает для серверов Linux/Unix.

## Открыть

- **ПК (Windows):** откроется Windows Terminal (если есть) или PowerShell с
  уже начатым входом. Ключ на диск в открытом виде не кладётся: терминал
  получает его от программы через её собственный агент SSH, который живёт
  две минуты и закрывается.
- **Linux:** терминал рабочего стола; нет рабочего стола — встроенный.
- **Телефон:** встроенный терминал. Под ним ряд клавиш: Esc, Tab, Ctrl
  (нажал — следующая буква пойдёт с Ctrl), стрелки, ^C, ^D, `|`, `~`.

## Ключ сервера

При первом входе программа запоминает ключ сервера. Если потом он
изменился — вход отклоняется: сервер переустановили или это подмена. Если
ты точно знаешь, что сервер переустанавливали, — «Забыть ключ сервера» в
сообщении об ошибке.
