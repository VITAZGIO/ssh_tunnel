# Удалённый стол

Рабочий стол Windows-машины по RDP — с компьютера и с телефона, из дома и не
из дома, без проброса портов и белого адреса.

## Ретранслятор RDP — поставить один раз

Сам протокол RDP разбирает **ретранслятор** — программа guacd (Apache
Guacamole). Он стоит на компьютере **в той же локальной сети, что и машины**
(лучше на том, что всегда включён: домашний сервер, NAS), разговаривает с
Windows по RDP, а ssh_tunnel — с ним. У плагина значок антенны — это и есть
напоминание: без ретранслятора не работает.

Поставить на Linux с Docker:

    docker run -d --name guacd --restart unless-stopped -p 4822:4822 guacamole/guacd

Потом в плагине вверху «Ретранслятор RDP» впиши его адрес и «Сохранить и
проверить»:

- через сеть устройств — **имя.mesh:4822** (например ubuntu.mesh:4822):
  работает отовсюду, где есть сеть устройств; на компьютере с guacd в
  «Сети устройств» должно быть включено «Пускать другие устройства к моим
  службам»;
- в локальной сети — **адрес:4822** (например 192.168.1.201:4822) — только
  из дома.

Зелёная антенна и «на связи» — ретранслятор отвечает.

## Машины

«Добавить»: имя и **адрес машины в домашней сети** (например 192.168.1.202)
— тот, по которому её видит ретранслятор, а не телефон. Пользователь Windows
и пароль можно запомнить на этом устройстве (файл доступен только программе)
— тогда подключение в одну кнопку. Не запомнил — спросит при подключении.

На самой Windows должно быть включено «Удалённый рабочий стол» (Параметры →
Система → Удалённый рабочий стол; Windows Pro).

## В сеансе

Сверху — строка кнопок (листается вбок):

- **⌨** — экранная клавиатура (только по кнопке: тап по экрану её не
  вызывает). Буквы уходят Юникодом — печатается то, что набрал, при любой
  раскладке Windows;
- **Тачпад / Касание** — палец двигает курсор, как на ноутбуке, или
  нажимает прямо туда, куда коснулся;
- **Ctrl, Alt, Shift, Win** — залипают на одно нажатие;
- Esc, Tab, стрелки, **Ctrl+Alt+Del**, **Alt+Tab**;
- **качество** — «Чётко», «Обычно», «Слабая связь»;
- **⛶** — во весь экран, **✕** — отключить.

Повернул телефон или растянул окно — Windows сама меняет разрешение.
Пропала связь — программа переподключается сама, Windows держит сеанс, и
ты возвращаешься туда же.
