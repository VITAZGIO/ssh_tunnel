# Файлы устройства

Смотреть, скачивать и загружать файлы других устройств твоей сети — как на
vitazgio.ru, только без сайта: напрямую через сеть устройств.

## Кто что видит

По умолчанию другим **не видно ничего**. На каждом устройстве сам
отмечаешь папки: «Файлы устройства» → **«Мои папки»** → выбрать обычную
папку (Фото, Загрузки, Документы…) или вписать путь → «Открыть».

- Открытую папку видят все устройства твоей сети устройств — только
  смотреть и скачивать.
- Галочка **«можно менять»** у папки (по умолчанию выключена) разрешает
  загружать в неё, создавать папки, переименовывать и удалять.
- Служба файлов доступна **только из сети устройств**: из интернета и из
  домашней сети её не видно. Кто пришёл, знает сервер сети — подделать
  чужое устройство нельзя.
- Приложение должно быть добавлено на обоих устройствах.

## Работа с файлами

Вкладка «Устройства» → выбрать устройство → папку.

- Нажать на фото, видео или текст — просмотр; на остальное — скачать.
- **Скачать:** на ПК — как обычная загрузка браузера; на телефоне — в
  «Загрузки», повтор после обрыва продолжает с места обрыва.
- **«Загрузить сюда»** — файлы уходят кусками; оборвалась связь — загрузка
  сама продолжится, а при повторе — с места обрыва. Файл с таким же именем
  не затирается: новый получит имя «файл (2)».
- Создать папку, переименовать, удалить — в папках с «можно менять».
  Удаление спрашивает подтверждение, непустую папку — ещё раз.

## Телефон

- Чтобы другие видели папки телефона, Android должен разрешить программе
  **«Доступ ко всем файлам»** — кнопка «Разрешить» во вкладке «Мои папки».
- Уведомление с прогрессом есть **только во время передачи**, потом оно
  убирается само (значок VPN Android показывает всегда — его убрать нельзя).

На ПК приложение сразу открывается отдельным окном.
