# Образец

Пустое приложение для проверки каркаса «Дополнительных приложений». В
выпущенных версиях его нет.

- Добавить: «Дополнительные приложения» → «+» → «Добавить».
- Звёздочка на плитке — приложение появится в быстром доступе на главном
  экране (стрелка под настройками).
- Выключатель на плитке — для фоновых приложений: выключенное не работает и
  не открывается.
- «⧉ В окне» в шапке — открыть отдельным окном (ПК и Linux).
- Убрать — «⋯» на плитке → «Убрать».
