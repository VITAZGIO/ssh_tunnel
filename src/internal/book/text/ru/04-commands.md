# Команды и нейросеть

Всё, что нажимается в окне, можно сделать командой — в PowerShell, в
терминале Linux, из своего скрипта. А можно отдать кнопки нейросети на этом
компьютере (Claude Desktop, Claude Code): она сама включит «Обход» или
добавит правило.

Команды работают с уже запущенной программой: окно (или служба) должно
работать. Команда находит его сама по файлу `api.json` в папке настроек.

## Команды

В PowerShell (на Linux — `ssh_tunnel_linux` вместо `ssh_tunnel.exe`):

- `ssh_tunnel.exe state` — что сейчас: туннель, сеть устройств, режим.
- `ssh_tunnel.exe tunnel off` — выключить туннель. Сеть устройств остаётся
  как была. `tunnel on` — включить и дождаться подключения.
- `ssh_tunnel.exe mesh on` или `mesh off` — сеть устройств.
- `ssh_tunnel.exe rules` — правила сервера. `rules add direct youtube.com` —
  всегда напрямую, `rules add tunnel site.ru` — всегда через сервер,
  `rules add app steam.exe` — программа в список фильтра, `rules remove …` —
  убрать, `rules mode only` — через туннель только программы из списка.
  `rules fakeip on|off` — подставные адреса в DNS режима VPN, `rules add realip
  .deepseek.com` — имени всегда настоящий адрес.
- `ssh_tunnel.exe apps` — плагины: `apps add calendar`,
  `apps remove …`, `apps star …`, `apps on …`, `apps off …`.
- `ssh_tunnel.exe check` — самопроверка, `check site youtube.com` —
  проверить сайт (нужно приложение «Проверить сайт»).
- `ssh_tunnel.exe help` — все команды. Список строится по самой программе:
  что появилось в новой версии, сразу есть и в командах.

Ответ — текстом. Для скриптов добавь `--json`, например
`$s = ssh_tunnel.exe state --json | ConvertFrom-Json`.

Код выхода: 0 — получилось, 1 — ошибка, 3 — программа не запущена.

На Windows программа оконная, поэтому в PowerShell ответ может напечататься
уже после приглашения `PS>`. Чтобы дождаться ответа —
`ssh_tunnel.exe state | Out-String`.

## Нейросеть (MCP)

1. В настройках программы поставь галочку **«Управление нейросетью
   (MCP)»**. Пока она снята, нейросеть ничего не может, даже если
   подключена. Галочка своя на каждом устройстве.
2. Подключи программу к нейросети.

**Claude Code** — одна команда в терминале:
`claude mcp add ssh_tunnel -- "C:\путь\к\ssh_tunnel.exe" mcp`

**Claude Desktop** — Настройки → Разработчик → «Изменить конфигурацию».
В файле `claude_desktop_config.json` внутри `mcpServers` добавь:
`"ssh_tunnel": {"command": "C:\\путь\\к\\ssh_tunnel.exe", "args": ["mcp"]}`
и перезапусти Claude Desktop.

Теперь можно просить: «включи обход», «пусть youtube.com идёт напрямую»,
«что с сетью устройств».

Наружу ничего не открывается: нейросеть сама запускает программу и говорит
с ней напрямую, по сети к этому не подключиться.

Опасные действия — выключить сеть устройств, удалить сервер или приложение,
остановить чужую программу, заменить настройки — помечены для нейросети
«спроси человека». Хорошая нейросеть сначала спросит тебя.

## Пароль на панель (Linux)

Панель Linux, открытая для локальной сети (`-web-lan`), может спрашивать пароль: «Настройки приложения» → «Дополнительно» → «Вход по паролю», затем «Задать пароль». Пока пароль не задан — не спрашивает.

Забыл пароль — на сервере под root:

```
ssh_tunnel_vpn_linux -reset-password
systemctl restart ssh_tunnel
```

(имя программы и службы — твои; точную команду показывает «Забыли пароль?» на экране входа).

## Обновление

«Настройки приложения» → «Проверить обновления» → «Обновить»: программа сама скачает новую версию, сверит контрольную сумму, поставит и перезапустится. Только по кнопке.
