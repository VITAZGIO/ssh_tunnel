# Книга

Справка, встроенная в программу (пункт меню «Книга»). Работает без интернета:
текст отсюда копируется в `src/internal/book/text/` и встраивается в сборку.
Правишь здесь — запусти `cd src && go generate ./internal/book`; тест
`go test ./internal/book` упадёт, если копии разошлись.

- `ru/`, `en/` — по языку интерфейса. Имена файлов одинаковые.
- `NN-<id>.md` — главы по порядку; первая строка `# Заголовок`.
- `app-<id>.md` — глава дополнительного приложения: её подхватывает каталог
  (поле `Book` в `src/internal/addons/manifest.go`), в Книге она стоит перед
  «Частыми проблемами» (`90-problems.md`).
- Без скриншотов (пока). Разметка — простой Markdown: заголовки `#`/`##`,
  абзацы, списки `-` и `1.`, **жирный**, `код`, ссылки `[текст](адрес)`.
