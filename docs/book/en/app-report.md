# Support report

Collects everything needed to sort out a problem into one file (zip):

- the log for the last few days;
- settings — passwords, keys and tokens are replaced with `***`;
- fresh results of "Check a site", "Who touches traffic", "Leak check";
- app version, system, network adapters.

First the app **shows what is inside** — every file can be opened and read.
Then:

- **"Save"** — the file goes to the Downloads folder;
- **"Share"** — the file goes to the clipboard (paste it into a messenger or an
  email) and the folder with it opens.

Nothing is sent to the server — you pass the report on yourself.
