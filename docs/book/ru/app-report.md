# Отчёт для поддержки

Собирает всё, что нужно, чтобы разобраться в проблеме, в один файл (zip):

- журнал за последние дни;
- настройки — пароли, ключи и токены заменены на `***`;
- свежие результаты «Проверить сайт», «Кто трогает трафик», «Проверка утечек»;
- версия программы, система, сетевые адаптеры.

Сначала программа **показывает, что внутри** — каждый файл можно раскрыть и
прочитать. Потом:

- **«Сохранить»** — файл в папку «Загрузки»;
- **«Поделиться»** — файл в буфер обмена (вставь его в мессенджер или письмо)
  и окно папки с ним.

На сервер ничего не отправляется — отчёт передаёшь сам.
