# Пароли

Свои пароли — на всех своих устройствах, под одним **главным паролем**.
Подставляются сами: в приложениях телефона и в браузере на компьютере
(Яндекс Браузер, Chrome, Edge).

## Начало

Первый раз — придумать главный пароль (не короче 8 знаков). Его нигде не
хранят: забудешь — пароли не открыть. На других своих устройствах открой
«Пароли» **тем же** главным паролем — записи синхронизируются сами по сети
устройств (и кнопкой «Синхронизировать»). Удалённая запись удаляется везде.

Хранилище зашифровано (AES-256, ключ из главного пароля); другим
устройствам уходит только зашифрованный файл. 🔒 вверху — закрыть пароли.

## Записи

«Добавить»: название, **сайт или приложение** (например mail.ru — тогда
подойдёт и e.mail.ru), логин, пароль («Придумать» — случайный надёжный),
заметка. В списке — «логин» и «пароль» копируют одним нажатием.

## Телефон: автозаполнение

«Выбрать ssh_tunnel для автозаполнения» — в системном окне выбрать
ssh_tunnel. Дальше в поле логина или пароля любого приложения появится
подсказка 🔑 с твоими логинами. Пароли закрыты — подсказка «открыть»
спросит главный пароль. Вошёл с новым паролем — Android предложит
сохранить его сюда. Браузер подставляет через автозаполнение, если в его
настройках разрешена «другая служба автозаполнения».

## Компьютер: расширение браузера

1. «Установить расширение» — программа положит папку
   ssh_tunnel-passwords-extension в «Загрузки».
2. В браузере открой browser://extensions (Chrome — chrome://extensions),
   включи «Режим разработчика» → «Загрузить распакованное» → эта папка.
3. «Новый ключ сопряжения» → скопируй ключ в окно расширения (значок у
   адресной строки) → «Сохранить».

Теперь в поле пароля на сайте появится список твоих логинов; вошёл с новым
паролем — расширение предложит запомнить. Расширение говорит только с
ssh_tunnel на этом же компьютере и только с ключом сопряжения.
