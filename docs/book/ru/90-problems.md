# Частые проблемы

## Не подключается

- Нажми **Проверка** на главном экране: она по шагам покажет, где рвётся —
  сеть, адрес сервера, порт, ключ.
- «Сервер не принял ключ» — устройство могли заморозить или удалить в панели
  сервера, либо выбран не тот ключ.
- «Сервер не отвечает» — проверь адрес и порт сервера.

## Подключено, но сайты не открываются

- Посмотри журнал (значок с полосками сверху): там видно, куда идёт каждое
  соединение.
- Сайт в списке «напрямую»? Тогда он идёт мимо сервера — и провайдер может
  его блокировать.

## Пропал интернет после закрытия программы

Программа при выходе сама снимает системный прокси. Если она закрылась
аварийно — запусти её и выйди через значок у часов → «Выход».

## Окно спряталось

Крестик прячет окно в значок у часов, туннель продолжает работать. Если
значка не видно — нажми стрелку «^» рядом с часами. Выход — правый щелчок по
значку → «Выход». Отдельные окна (Книга, приложения) живут сами по себе и
закрываются своим крестиком.

## Не открывается роутер, принтер или NAS

Локальная сеть по умолчанию идёт напрямую. Если включено «локальную сеть
через туннель» — выключи.
