# С чего начать

ssh_tunnel пускает интернет через твой собственный сервер по SSH. Провайдер
видит одно зашифрованное соединение с сервером — как у администратора, который
заходит на свою машину. SSH не блокируют: без него не работает половина
интернета.

## Что нужно

- **Сервер** (VPS) с SSH. Подойдёт самый дешёвый.
- **Ключ** для входа на него. Программа умеет создать ключ сама.

## Первый запуск

1. Открой **Настройки → Мастер настройки** и выбери, что есть: новый сервер,
   готовый сервер или данные от того, кто уже всё настроил.
2. Мастер проверит вход, настроит сервер и добавит его в список.
3. На главном экране нажми большую круглую кнопку. «Защищено» — всё работает.

## Телефон

Самый быстрый путь — **Настройки → Мастер настройки → Подключить телефон**:
на экране появится QR-код, телефон считывает его камерой.

## Где что

- **Главный экран** — две кнопки и состояние связи (глава «Главный экран и
  режимы»).
- **Настройки** — серверы, программы, сеть устройств, оформление.
- **Дополнительные приложения** — то, что добавляешь сам, по желанию.
- **Книга** — эта справка. Поиск — сверху, исходники — по ссылке внизу.
