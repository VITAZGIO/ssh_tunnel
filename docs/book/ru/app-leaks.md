# Проверка утечек

Проверяет, не видно ли твой настоящий адрес, когда VPN включён.

## Что показывает

- **Какой адрес видят сайты** — страна и провайдер. Сначала спрашивает свою
  точку на панели сервера, если её нет — запасной внешний сервис.
- **Чей DNS отвечает** — если имена сайтов спрашиваются у провайдера мимо
  туннеля, это утечка DNS.
- **IPv6** — не уходит ли трафик по IPv6 мимо туннеля.

Итог — одной фразой. Если утечка и её можно закрыть настройкой, появляется
кнопка **«Исправить»** (например, включить системный прокси).

## WebRTC

Браузер может выдать адрес через WebRTC. Кнопка **«Открыть в браузере»**
открывает маленькую проверочную страницу на панели твоего сервера — она
ничего не хранит и никуда не отправляет. Есть, если сервер выдан панелью.

## Молча, при каждом подключении

Пока приложение включено (выключатель на плитке), программа проверяет утечки
после каждого подключения и пишет в журнал **только если нашла утечку**.
