# Образец

Пустой плагин для проверки каркаса «Плагинов». В
выпущенных версиях его нет.

- Добавить: «Плагины» → «+» → «Добавить».
- Звёздочка на плитке — плагин появится в быстром доступе на главном
  экране (стрелка вниз в шапке, слева от журнала).
- Выключатель на плитке — для фоновых плагинов: выключенный не работает и
  не открывается.
- «⧉ В окне» в шапке — открыть отдельным окном (ПК и Linux).
- Убрать — «⋯» на плитке → «Убрать».
