# Доступ

Раздел **Доступ** решает, кто к кому может ходить внутри сети устройств.
Например, ноутбук может открыть сайт на домашнем сервере, а телефон — нет.

## Главное правило: права у пользователя, не у устройства

Права принадлежат **SSH-пользователю**, а не устройству. Устройство входит на
сервер под своим пользователем. Правила, которые ты задаёшь, применяются к
этому пользователю. Поэтому права нельзя подделать, зайдя с другого
устройства под чужим пользователем.

Из этого следует простое правило: если два устройства пришли под одним
пользователем, у них одни и те же права.

## Два режима

В разделе есть два режима. Переключатель — **Включить простой режим**.

### Простой режим

Простой режим показывает таблицу с галочками. Каждому устройству назначают
роль:

- **Моё устройство** — ходит ко всем, кроме гостей;
- **Сервер** — к нему ходят, сам никуда;
- **Гость** — только интернет: сеть его не видит, к нему никто не ходит.

Для каждой роли есть колонка **Куда может ходить**: **Ко всем** или
**Никуда**, и галочки по устройствам. Простой режим записывает всё правилами
сам. Он не трогает правила, которые ты задал вручную в расширенном режиме:
такие галочки показаны как заданные правилами расширенного режима.

### Расширенное: группы и правила

В расширенном режиме есть два списка:

- **группы** — устройства кладёшь в группы (кнопка **Права** у устройства);
- **правила** — «откуда → куда», с портами. Пусто — все порты. Можно писать
  список: `22,80,8000-8100`.

Есть две особые группы: **«Все»** — все устройства и серверы, **«Серверы»** —
сами серверы сети. Правило «A → B» разрешает открывать соединения от A к B.
Обратно можно только если есть правило в другую сторону.

Пределы такие: не больше 64 групп и 256 правил. Если сохранение их превысит,
панель ничего не запишет и напишет, сколько нужно и сколько разрешено.

## Как применяются изменения

Новые правила действуют на новые соединения. Уже идущие соединения правило не
рвёт. Чтобы оборвать их, переподключи устройство.

Правила хранятся на каждом сервере отдельно. Если на двух серверах правила
разные, панель напишет «правила другие». Задай одинаковые на всех серверах.

## Без сервера

Правила проверяет только сервер. Без сервера правила никто не проверяет:
устройства пускаются только из последнего списка, который сервер успел
передать. Подробно — в главе «Сеть без сервера».
