# Первый вход

Панель при первом запуске создаёт учётную запись `admin` и одноразовый
пароль. Пароль нигде не хранится, кроме журнала службы. Посмотреть его можно
командой:

```bash
journalctl -u ssh_tunnel_panel -n 50
```

Сразу после входа панель попросит сменить пароль. Этот пароль должен быть
длинным и уникальным. Панель замедляет перебор паролей сама: после неудачных входов растёт задержка
перед ответом, а после нескольких неудач вход блокируется. Это не замена
нормальному паролю.

## Сменить пароль

1. Открой **Настройки** → блок **Учётная запись**.
2. Нажми **Сменить пароль**.
3. Введи **Текущий пароль**, затем **Новый пароль** и повтори его.
4. Нажми **Задать пароль**.

Если одноразовый пароль потерян и вход больше невозможен, сбрось учётку. Удали
файл `/etc/ssh_tunnel_panel/users.json` и перезапусти службу:

```bash
sudo rm /etc/ssh_tunnel_panel/users.json
sudo systemctl restart ssh_tunnel_panel
```

Панель заведёт новую одноразовую учётку, как при первом запуске. Список
устройств при этом не трогается: он хранится отдельно.

## Домен и сертификат

В самой панели нет поля для домена и сертификата. Они задаются при установке
флагами. Есть два варианта, переключаются флагами без переустановки:

1. **За своим reverse proxy** (nginx или Caddy). Панель слушает только
   `127.0.0.1:47823`, сертификат выдаёт прокси. Прокси должен передавать
   заголовок `X-Forwarded-Proto`: по нему панель ставит cookie входа с флагом
   `Secure`.
2. **Встроенный сертификат.** Установка с флагом `--domain=panel.example.com`.
   Панель сама получает сертификат Let's Encrypt и слушает порты 443 и 80.
   Домен до запуска должен указывать на сервер записью A. Иначе сертификат не
   выпустится.

Не держи панель голым HTTP на порту, открытом в интернет.

## Если страница не открывается

Проверь по порядку:

1. **Служба запущена?** Посмотри журнал командой из начала главы. Ошибки
   запуска пишутся туда.
2. **Ты заходишь на правильный адрес?** Без `--domain` панель слушает только
   `127.0.0.1:47823`. Снаружи её не видно. Заходи через SSH-туннель или
   поставь прокси.
3. **Порт открыт?** Фаервол перед панелью (ufw и подобные) должен пускать
   порт панели. С `--domain` это 80 и 443.
4. **Домен указывает на сервер?** Если домен не смотрит на сервер, сертификат
   не получится, и страница по HTTPS не откроется.

## Автозапуск

**Настройки** → **Автозапуск** → галочка **Запускать при старте системы**.
Если галочку снять, панель сама не поднимется после перезагрузки сервера. Уже
работающую панель галочка не выключает.
