# Серверы сети

У сети устройств может быть несколько серверов. Главного среди них нет: каждый
сервер сам по себе, со своим `meshd` (служба сети на сервере). Устройство
держит связь со всеми серверами, профили которых у него есть. Все они
используют один ключ сети.

## Как добавить сервер

Сервер попадает в сеть, когда на устройстве есть его профиль с тем же ключом
сети и включённой сетью устройств. Панель помогает найти такие серверы:

1. Открой **Сети** → **Серверы сети**.
2. В блоке **Советовать устройствам** введи **Имя**, **Адрес сервера** и
   **Порт** и нажми **Добавить сервер**.

Устройства этого сервера узнают из списка, какие серверы ещё есть в сети. В
карточке устройства такие серверы видны внизу списка, с кнопкой
**Добавить профиль**. Адрес и ключ сети подставятся сами. Пользователя и ключ
сервера впиши сам.

## Переход со старого способа

Раньше второй сервер подключали «побочным» способом: через проброс порта к
`meshd` главного сервера. Такой сервер в панели помечен как старый способ.
Чтобы перейти на свою службу сети, открой **Настройки** → **Перейти на свою
службу сети** на этом сервере.

Порядок такой:

1. Обнови `meshd` на первом сервере (см. главу «Обновление»).
2. У каждого устройства добавь оба профиля с одним ключом сети. Устройство
   увидит оба сервера.
3. На втором сервере нажми **Перейти на свою службу сети**. Старый
   пробрасывающий процесс останавливается, а адрес в сети остаётся прежним.
4. Задай одинаковые правила доступа в обеих панелях.

## Если один сервер пропал

Устройства держат связь со всеми серверами, поэтому пропажа одного сервера
обычно незаметна. Буфер, файлы и связь между устройствами идут через второй
сервер, у которого есть общее устройство. Прямые соединения между устройствами
не замечают ничего.

Если общего живого сервера нет, программа на устройстве пишет «нет общего
сервера: оно на связи через …». Так бывает, когда два устройства имеют
профили разных серверов, и ни один не доступен обоим.

## Что на каждом сервере своё

Эти вещи у каждого сервера свои:

- правила доступа;
- журнал;
- одобрение новых устройств;
- заморозка устройств «в сети»;
- удаление устройства и сети.

Если поменять что-то одно, другие серверы не узнают. Поэтому на всех серверах
должны быть одинаковые правила. Иначе панель пишет «правила другие».

## Что едет вместе с устройством

Устройство само хранит свой адрес и имя в сети. Они одинаковы на всех серверах,
которые его видят:

- **Имя устройства.** Если его переименовать на одном сервере, на других оно
  тоже сменится. Побеждает последняя правка.
- **Адрес в сети.** При конфликте выигрывает тот, кто держит адрес дольше.
  При равенстве побеждает меньший идентификатор.

Адрес самого сервера в сети у каждого свой. Не привязывай к нему настройки.

## Известное ограничение

Android пока работает только с одним сервером. Несколько серверов на
телефоне не поддерживаются. Подробно про телефон — в Книге программы.
