# Обновление

Обновляются три вещи: служба сети `meshd` на каждом сервере, хост плагинов и
сама панель. Программа на устройствах обновляется последней.

## Порядок

Сначала серверы, потом устройства:

1. **`meshd` на каждом сервере.** Кнопка **Обновить meshd** в **Настройках**.
   Версия 5 нужна для одобрения новых устройств и заморозки в сети.
2. **Хост плагинов.** Если плагины стоят, нажми **Обновить** в карточке хоста.
3. **Программа на устройствах.** Обновляй её после серверов.

Если серверов несколько, обновляй их по одному.

Почему `meshd` первым: одобрение новых устройств и заморозка в сети работают
только с версией 5 службы. Старая служба их не понимает.

## Панель

**Настройки** → блок **Версия панели** → **Проверить обновления**. Если вышла
новая версия, появится кнопка **Обновить до …**.

Панель сама скачает свой файл из релиза на GitHub. Сверит его с контрольной
суммой. Подменит файл и перезапустится. Это занимает около минуты. Страница
сама обновится, входить заново не нужно. Подключённые устройства не
затрагиваются.

Если у сервера нет выхода в интернет, проверка обновлений не сработает. Панель
напишет, что не может связаться с GitHub.

## Версии до 1.7.3

Старые версии панели кнопки обновления не имеют. Их один раз обновляют
командой от root. Команда записана в инструкции по установке панели в
репозитории на GitHub. Дальше можно обновляться из настроек.

## Сброс пароля

Если пароль потерян, сбрось учётку. Удали файл `users.json` и перезапусти
службу. Подробно — в главе «Первый вход».

## Смена порта панели

Порт панели задаётся флагом `-listen`. По умолчанию это `127.0.0.1:47823`.
Чтобы сменить порт, поправь строку `ExecStart` в службе и перезапусти её:

```bash
sudo sed -i 's|^ExecStart=.*|ExecStart=/usr/local/bin/ssh_tunnel_panel -listen 127.0.0.1:8443|' \
  /etc/systemd/system/ssh_tunnel_panel.service
sudo systemctl daemon-reload
sudo systemctl restart ssh_tunnel_panel
```

С флагом `-domain` порт не важен: панель слушает `:80` и `:443`.

## Проверка после обновления

Сделай это после каждого обновления:

1. **Хост плагинов запущен.** Если плагины стоят, проверь службу командой
   `systemctl status ssh_tunnel_node`. Если служба не стартует, пришли вывод
   `journalctl -u ssh_tunnel_node -n 50`.
2. **Порты плагинов открыты.** Открой «Что мешает плагинам» и нажми
   **Открыть порты плагинов», если там что-то написано.
3. **Устройства видят друг друга.** Открой **Сети** и проверь, что каждое
   устройство на связи.
4. **Программы на устройствах обновлены.** Их обновляют после серверов, см.
   «Порядок» выше.
