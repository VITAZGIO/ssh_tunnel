# Резервные копии

Резервные копии лежат на сервере. Папку на устройстве по расписанию копирует
программа, а хранит сервер. Копии идут только по сети устройств, не через
интернет.

## Что видно в панели

В разделе **Плагины** есть блок **Резервные копии**. Для каждой копии видно:

- **версий** — сколько версий хранится;
- **держать** — сколько версий оставлять;
- **последняя** — когда была последняя удачная копия;
- **на диске** — сколько места занято. Одинаковое содержимое хранится один раз.

Кнопка **Удалить** убирает копию со всеми версиями. Это нельзя отменить, панель
спросит подтверждение.

## Расписание и версии задаются на устройстве

Расписание, папку и число версий задаёт программа на устройстве. Панель их
только показывает. В программе есть:

- **раз в день** или **раз в неделю**;
- **после изменений**, когда папка молчит заданное число минут;
- **сколько версий держать** — лишние сервер убирает сам.

Подробно — в Книге программы, глава «Резервные копии».

## Что будет, когда кончится место

Квота общая для всех плагинов сети (см. главу «Плагины сервера»). Когда место
кончается, сервер сначала убирает **самую старую версию той же копии** сверх
«держать». Чужие копии он не трогает.

Если и так места не хватает, новая копия останавливается. Устройство получит
ответ «на сервере кончилось место». Уже записанное не портится.

## Восстановление

Восстанавливает файлы программа на устройстве, не панель. Из любой версии можно
вернуть один файл или всю папку.

Восстановление **никогда не перезаписывает файлы молча**. Если файл на
устройстве отличается от копии, восстановленный ложится рядом. Его имя
содержит пометку «(из копии …)». Старый файл остаётся на месте.

## Кто видит чьи копии

Читать копию может только устройство, которое её создало, и устройства того же
SSH-пользователя. Другие устройства сети копий не видят. Это правило не
отменяют даже открытые права доступа.

## Пример

Ноутбук делает копию своей папки «Документы» на сервер. Телефон того же
SSH-пользователя видит эту копию и может восстановить из неё файл. Если на
телефоне уже есть файл с таким именем, но другим содержимым, восстановленный
ляжет рядом с пометкой «(из копии …)». Старый файл не трогается.

Устройство другого SSH-пользователя ту же копию не увидит, даже если сеть одна.
