# Ссылка импорта сервера `sshtunnel://`

Ссылку и QR-код с ней показывает панель сервера (`ssh_tunnel_panel`) **один
раз — сразу после создания клиента** `tun_*`. У существующих клиентов их нет
(«Показать настройки» отдаёт только файл и поля для ручного ввода).

## Где читается
- **Android:** «Сканировать QR» в списке серверов, «Вставить» из буфера,
  а также сама ссылка — её открывает системная камера или браузер
  (`intent-filter` `sshtunnel://import`).
- **ПК/Linux:** кнопка «Вставить» на экране серверов (ссылка в буфере).
- Везде разбор один — `share.Parse` (`src/internal/share/link.go`): ссылку он
  понимает наравне с JSON-файлом экспорта.

## Формат

```
sshtunnel://import?v=1&d=<base64url без "=" от JSON>
```

`v` — версия содержимого (сейчас `1`; новые необязательные поля версию не
меняют). JSON в `d` — только то, что нужно для входа этого аккаунта:

| Ключ | Что | Обязателен |
|---|---|---|
| `h` | адрес SSH-сервера | да |
| `u` | пользователь (`tun_…`) | да |
| `p` | порт SSH; нет — 22 | нет |
| `k` | приватный ключ OpenSSH целиком; нет — ключ укажут руками | нет |
| `n` | имя сервера в программе; нет — адрес | нет |
| `pn`, `c`, `dn` | адрес панели, id клиента, имя устройства (сервер «выдан панелью») | нет |

Порты прокси, пул и фильтр в ссылку не входят: при импорте берутся
стандартные (1080/1081, 4, «всё через туннель»).

Ссылка содержит приватный ключ — передавать её только владельцу устройства.
