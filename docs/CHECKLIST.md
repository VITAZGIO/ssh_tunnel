# Проверка перед релизом (руками: Windows + Android + Linux)

Автотесты этого не покрывают: адаптер, маршруты, DNS системы и точку
доступа проверить можно только на живой системе.

1. **Все переходы между 4 режимами** — каждая кнопка вкл/выкл в любом
   порядке: работает без перезагрузки, вторая кнопка не дёргается.
2. **После «Выключено»:** IP на сайтах (2ip.ru) — провайдерский; в маршрутах
   (`route print` / `ip route`) и DNS (`ipconfig /all`, `resolvectl status`)
   нет ничего нашего.
3. **Обход → только сеть устройств:** открытая во время обхода вкладка с
   2ip.ru после обновления показывает свой адрес (не сервера); RDP к
   устройству сети не рвётся.
4. **Wi-Fi ↔ кабель и сон/пробуждение** в каждом режиме — всё
   восстанавливается само.
5. **NetBird в исключениях** при включённом «Обходе»: `netbird status` —
   Connected, пиры доступны.
6. **«Напрямую» по правилам** реально идёт мимо адаптера: сайт в «всегда
   напрямую» показывает свой IP; с включённой мобильной точкой доступа —
   тоже (Windows).
7. **Нажатие во время «Подключаюсь…»** отменяет, ничего не висит; вторая
   кнопка при этом не меняется.
8. **Перезапуск и автозапуск** с «как при закрытии» восстанавливают обе
   кнопки.
9. **API:** `api.json` появился; `GET /api/state` и `POST /api/state`
   работают из PowerShell (см. `docs/API.md`).

## Плагины, Книга, отдельные окна (ТЗ 2)

Образец приложения виден только в сборке `dev` (без версии): проверять на
ней, в релизе каталог пуст.

10. **Каталог:** Настройки → «Плагины» — первый раз пусто;
    «+» → «Образец» → «Добавить». Звёздочка, выключатель «в фоне», «⋯» →
    «Убрать». **Перезапуск программы** — всё как было. На другом устройстве
    список свой (пустой).
11. **Выключенное не открывается:** выключить Образец на плитке — плитка
    бледная, при нажатии «выключено»; `GET /addons/sample.html?t=…` — 404.
12. **Быстрый доступ:** звёздочка у Образца → на главном справа под
    настройками стрелка → панель с ним. Сняли звёздочку — стрелки нет. То же
    на телефоне (стрелка → меню).
13. **Первое открытие:** подсказка + «Подробнее — в Книге»; после «OK» больше
    не показывается (и после перезапуска). «?» в шапке открывает главу.
14. **Отдельные окна (Windows):** «⧉ В окне» у Образца и Книга — два окна
    сразу; подвинуть/растянуть, закрыть, открыть снова — на том же месте.
    Крестик главного окна прячет его в трей — отдельные окна остаются. То же в
    VPN-версии (окно службы). Повторное «В окне» — показывает уже открытое.
    «Здесь» в отдельном окне закрывает его; следующий запуск (в том числе из
    быстрого доступа) — внутри приложения.
15. **Книга:** обе локали (переключить язык в настройках); поиск находит
    слово и подсвечивает его; на ПК листается страницами (кнопки, стрелки,
    колесо), в широком окне — разворот; на телефоне — прокрутка. Ссылка на
    GitHub внизу открывает браузер. Без интернета Книга открывается.
16. **Android = тот же HTML:** «Плагины» и «Книга» на
    телефоне — те же страницы, что на ПК (тёмная/светлая тема, язык). «Назад»
    из Книги, открытой с приложения, возвращает к приложению.
17. **Linux, «напрямую» на Fedora** (`sysctl net.ipv4.conf.all.rp_filter` = 1):
    обход включён, сайт из «всегда напрямую» открывается и показывает свой IP;
    `ip route | grep "proto 94"` — маршруты к адресу и серверу через роутер.
    После «Выключено» и после `kill -9` + повторного запуска маршрутов
    `proto 94` не остаётся.

## Android на общем HTML (ТЗ 2, второй PR)

Ставить поверх прежней версии (настройки и ключи должны сохраниться).

18. **Первый запуск после обновления:** серверы, ключи, выбор приложений,
    тема и язык — прежние. Главный экран — как на ПК (круглая кнопка, «Сеть
    устройств», цифры, тест скорости, самопроверка).
19. **VPN на свежей установке:** круглая кнопка → системный вопрос «разрешить
    VPN?» → «ОК» → подключается. «Отмена» → на кнопке ошибка, ничего не висит.
20. **Четыре режима на телефоне:** круглая и «Сеть устройств» включаются и
    выключаются по отдельности; нажатие во время «Подключаюсь…» отменяет;
    плитка в шторке и уведомление «Выключить» работают как раньше.
21. **Серверы:** «QR-код» (камера) и «Вставить» добавляют сервер из QR панели
    и из ссылки `sshtunnel://`; ссылка из мессенджера открывает приложение;
    «Вставить ключ» на сервере без ключа; «Выбрать этот сервер» переподключает.
22. **Программы через туннель:** «+ Добавить» — список приложений со значками
    и поиском; «Только выбранные» / «Все, кроме» действуют после переподключения.
23. **Настройки приложения:** домены, сеть устройств, запуск (включать при
    открытии), тема/фон, профили приложения, перенос настроек (буфер и файл),
    проверка и установка обновления. Реклама настраивается только в своём плагине.
24. **«Назад» телефона** возвращает на экран выше, с главного — сворачивает;
    стрелка быстрого доступа — только на главном экране.
25. **Мастер на телефоне** — только вкладка «Пользователь» (создание на
    сервере работает при подключённом туннеле).

## Диагностика (ТЗ 3)

26. **Проверить сайт:** заблокированный у провайдера сайт → «Провайдер
    блокирует, через VPN открывается», шаги напрямую красные на нужном шаге;
    «Пускать через VPN» — сайт появился в «всегда через сервер» в настройках.
    «Проверить популярные», правка списка, история из 10 — после перезапуска.
27. **Кто трогает (ноутбук с zapret):** находит zapret; «Нет» — ничего не
    трогается; «Разрешаю» → окно UAC → останавливает, YouTube оживает →
    «Вернуть как было» возвращает (winws.exe снова работает). «Отключить
    насовсем» — после перезагрузки не стартует, «Вернуть» — стартует.
    «Помирить» при `--ipset-exclude` — адрес сервера в файле, zapret работает.
    Если не помогло — «Дело не в нём, вернул как было».
28. **Ошибка подключения** на главном → кнопка «Проверить, кто мешает».
29. **Утечки:** при включённом обходе — «Утечек нет»; выключить системный
    прокси (режим прокси) → утечка + «Исправить». Страница WebRTC панели
    открывается в браузере. Молчаливая проверка пишет в журнал только при
    утечке.
30. **Отчёт:** предпросмотр, «Сохранить» → zip в «Загрузки», «Поделиться» →
    файл вставляется в Telegram. В zip нет ключей, `api.json`-токена,
    ключа сети (автотест `TestReportHasNoSecrets`).

31. **Устройства сети (ТЗ 4).** Карта сети: совпадает со схемой панели
    главного сервера, офлайн — серые с «был в сети N назад»; карточка → SSH,
    Файлы. SSH с ПК: добавить Ubuntu .201 из сети устройств → «Установить
    ключ» (пароль раз) → «Открыть» — Windows Terminal/PowerShell входит без
    пароля; `ssh_key.bin` в папке настроек начинается с `S` (зашифрован), в
    `%TEMP%` и `~/.ssh` ключа программы нет. VPN-версия — то же из окна службы.
    SSH с телефона: встроенный терминал, Ctrl+C и Tab работают. Файлы: на
    телефоне «Разрешить» доступ ко всем файлам, открыть «DCIM/Camera»; с ПК
    видно только её, фото открывается, скачивается; без «можно менять»
    загрузить/удалить нельзя, с ней — можно; уведомление на телефоне есть
    только во время передачи. Обрыв связи посреди загрузки большого файла —
    продолжается с места обрыва.

## Сеть без сервера, новая панель, общий буфер (заход 1, ТЗ 1–4)

- [ ] Сеть без сервера: два ПК в одной локальной сети, между ними «напрямую».
      Выдернуть кабель интернета из роутера — через полторы минуты сервера
      нет, второй ПК по-прежнему в сети. Скопировать текст на одном — пришёл
      на другой; файл в зеркальной папке — тоже. Телефон в том же Wi-Fi (экран
      включён) — то же.
- [ ] Перезапустить программу на одном ПК без интернета — известное
      ограничение: сеть устройств не поднимется, пока нет связи с сервером.
- [ ] Панель на сервере: открыть все пять разделов, ничего не пропало. Одно
      устройство — одна строка (и вход по SSH, и сеть устройств). Создать
      устройство, QR с телефона читается. Телефон: меню внизу не закрыто
      полосой жестов. Широкий монитор: колонки расходятся, схема читается.
- [ ] Панель побочного сервера: в «Настройках» связь с главным и журнал
      проброса. Обновление панели из «Настроек» доходит до конца.
- [ ] Новый meshd: после «Переустановить» устройства на месте. Старый meshd с
      новой панелью — страница работает, новое отвечает «обновите meshd».
- [ ] Общий буфер, телефон → ПК: фото из галереи через «Поделиться» —
      вставляется в Paint, в мессенджер и в Проводник (файлом). Скриншот — то
      же. Скопировал фото и открыл программу — ушло один раз, второй раз не
      уходит. Файл, пришедший с ПК, обратно не отправляется.
- [ ] Кнопка «Отправить буфер» в уведомлении: есть при включённом плагине,
      одно нажатие — буфер на ПК.
- [ ] Специальные возможности: включить (на Android 13+ — через «Разрешить
      ограниченные настройки»), нажать «Копировать» в другой программе —
      буфер на ПК. Оболочка телефона не выключает службу через время.

## Сеть без сервера при старте, панель, Docker (заход 2, ТЗ 5–7)

- [ ] Два ПК в одной локальной сети, оба хоть раз были в сети устройств.
      Выдернуть кабель интернета, перезагрузить один ПК. Через минуту-две:
      круглая кнопка с ошибкой сервера, «Сеть устройств» включена, в строке
      состояния «Без сервера, напрямую: 1», общий буфер между ПК работает.
- [ ] То же, второй ПК выключен: «Нет связи, соседей не видно», ничего не
      виснет, журнал не забит.
- [ ] `ssh_tunnel.exe state` — «Устройства: без сервера, напрямую: 1».
      VPN-версия: `ping <другой>.mesh` и RDP на него без сервера работают.
- [ ] Интернет вернулся: за полминуты оба ПК «В сети» без перезапуска.
      Выключить и включить кнопку сети — двойников в панели сервера нет.
- [ ] Панель, «Сети»: переименовать сеть, очистить имя — «Сеть N»; имя
      переживает перезапуск meshd. Удалить сеть с устройствами в сети —
      отвалились, в журнале запись, сеть вернулась пустой без имени.
- [ ] Панель, «Доступ»: «Включить простой режим» на своей политике — текст
      подтверждения по делу, после включения доступ не изменился. Снять
      галочку «ноутбук → ПК» — соединение отказано, в журнале «Отказано»,
      проверка отвечает «Нет». Перезагрузить страницу — таблица та же.
- [ ] Два компьютера с одним файлом настроек — одна строка «2 устр.».
      Устройство через побочный сервер — только для чтения. Телефон — список
      галочек вместо таблицы.
- [ ] Старый meshd: подсказка «обновите meshd» в «Сетях», «Доступе» и
      журнале, остальное работает. Перезапуск meshd: в журнале отметка,
      двойных записей нет.
- [ ] Docker (Linux, VPN-версия): плагин показывает контейнеры. Контейнер a
      «через сервер» — `curl ifconfig.me` даёт адрес сервера; b «напрямую» —
      домашний. Круглая кнопка выключена: у a интернета нет, у b есть.
- [ ] Docker: пересоздать контейнер a под тем же именем — снова через
      сервер. Контейнер с `-p` виден из локальной сети. `kill -9` программы:
      у a интернета нет; запуск — вернулся. `systemctl stop` — в `ip rule`
      нет 9400/9401.
- [ ] Docker на Fedora/RHEL (`rp_filter=1`): ответы не теряются, имена у a
      разрешаются.
