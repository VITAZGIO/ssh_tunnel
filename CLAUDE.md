# CLAUDE.md — правила для чатов, которые работают с ssh_tunnel

Отвечаем и пишем комментарии по-русски, коротко и по делу. Перед правкой —
прочитать этот файл, `docs/ARCHITECTURE.md` (раздел «Ядро 2.0») и
`docs/decisions.md`. Решение, принятое в чате, дописать в `docs/decisions.md`
(дата, что, почему) — не переписывать чужие записи, а добавлять свои.

## Где что
- **Ядро** — `src/internal/core`: две кнопки (`Machine`), одно место применения
  режима (`Driver.Apply`), одно решение «куда» (`Decide`, `DecideDNS`), план
  адаптера (`PlanVPN`), гигиена переключения (`Transition`). Одно на все
  платформы; Android получает его через gomobile (`android/core`).
- **Исполнение решений** — `src/internal/tunnel` (пул SSH, прокси, стек:
  `route.go` спрашивает ядро и делает), `src/internal/app` (драйвер ядра для
  Windows/Linux: связь, системный прокси, слой VPN).
- **Платформа** — только «как»: `vpn/vpnlayer` (Wintun/TUN, маршруты, DNS,
  привязка сокетов, маршруты к прямым адресам), служба Android
  (`android/app/.../TunnelService.kt`), `sysproxy`, `procinfo`.
- **Интерфейс** — один HTML: `src/internal/webui/assets/index.html`. API — в
  `src/internal/webui` (таблица маршрутов в `api.go`, описание — `docs/API.md`).

## Нельзя
- Логику «куда» (через сервер / напрямую / в сеть устройств / отказ) писать
  где-либо кроме `core.Decide`/`core.DecideDNS`. Платформа и интерфейс её не
  решают.
- Хранить состояние кнопок в интерфейсе: экран рисует `core.State` (событие
  `core`, `GET /api/state`) и шлёт только «хочу» (`POST /api/state`).
- Менять режим «кусочками»: любое изменение — через `Machine` → `Apply`
  целиком. Состояние после переключения = состояние после чистого запуска.
- Делать в интерфейсе то, чего нет в API: всё, что умеет экран, должно
  делаться через API (на нём PowerShell, MCP, сторонние программы).
- Предлагать замену SSH на другой протокол (см. README: SSH не блокируют).
- Номер 2.0 до готовности всех этапов 2.0: релизы идут как 1.x.

## Проверка
- `cd src && go test -race ./...` (Go 1.22+), `cd android/core && go test ./...`
  и `cd vpn && go test ./...` (Go 1.26). CI делает то же на ubuntu-latest.
- На машине, где через ssh_tunnel ходит сам разработчик, не гонять тесты
  `webui`: они поднимают туннель с системным прокси.
- Перед релизом — ручной чек-лист `docs/CHECKLIST.md`.

## Релиз
`gh workflow run release.yml -f tag=vX.Y.Z -f notes="…"` — собирает Windows,
Linux и Android с ветки main. Описание — что изменилось для человека.
